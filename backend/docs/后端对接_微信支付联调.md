## 5. 后端需要完成的工作（TODO 清单）

### 5.1 新增 `backend/src/utils/wechatPayV3.js`

需导出以下方法（与现有 `servicePaymentController.js` 调用一致）：

| 方法 | 职责 |
|------|------|
| `isWechatPayConfigured()` | 检查 env + 私钥是否可读 |
| `getWechatPayConfigStatus()` | 返回 `{ missing: string[], privateKeyLoadError? }` 供报错 |
| `yuanToFen(amount)` | 金额元 → 分（整数） |
| `jsapiUnifiedOrder({ out_trade_no, description, amountFen, notify_url, openid })` | 调用微信 `POST /v3/pay/transactions/jsapi` |
| `buildJsapiPayParams(prepayId)` | 生成小程序调起支付五参数（`signType: RSA`） |
| `verifyAndDecryptNotify(req)` | 支付回调：验签 + AES-GCM 解密 |

可参考 [微信支付官方 Node SDK](https://github.com/wechatpay-apiv3/wechatpay-node) 或自行实现 V3 签名（SHA256-RSA）。

**统一下单请求体要点**：

```json
{
  "appid": "wx563a4fb90c87e40d",
  "mchid": "1113234936",
  "description": "订单描述",
  "out_trade_no": "商户侧唯一单号",
  "notify_url": "https://jshsp1.eds-tech.cn/api/v1/market/pay/callback",
  "amount": { "total": 100, "currency": "CNY" },
  "payer": { "openid": "用户openid" }
}
```

**小程序五参数签名串**（调起支付）：

```
appId + "\n" + timeStamp + "\n" + nonceStr + "\n" + "prepay_id=xxx" + "\n"
```

### 5.2 本地集市：替换 mock 支付

当前 `market.controller.js` 的 `createPayment` 返回假参数（`signType: MD5`），**无法调起真收银台**。

建议二选一：

- **方案 A（推荐）**：新增 `backend/src/controllers/marketPaymentController.js`，逻辑对齐 `servicePaymentController.js`，订单表改为 `MarketOrder`
- **方案 B**：直接在 `market.controller.js` 内调用 `wechatPayV3`，替换 mock 实现

`createPayment` 需实现：

1. 校验登录、`order_no`、订单归属
2. 订单状态：`order_status === 'pending_payment'` 且 `pay_status === 'unpaid'`
3. 读取用户 `openid`，无则返回明确错误
4. 创建/复用 `market_pay_transactions` 流水（`pay_status: created`）
5. 调 `jsapiUnifiedOrder` 拿 `prepay_id`
6. 返回五参数（见第 6 节响应格式）

支付成功后业务逻辑（可参考现有 `mockPaymentSuccess`）：

- `MarketOrder.pay_status = 'paid'`
- `MarketOrder.order_status = 'pending_accept'`
- `paid_at` 写入
- 积分发放（`orderPoints.grantPointsOnOrderPaid`）
- 分佣（`commissionService.distributeCommission`）

### 5.3 支付回调 `payCallback`

在 `backend/src/modules/market/routes.js` 注册（**不要加 JWT 中间件**）：

```js
router.post('/pay/callback', marketPaymentController.payCallback);
```

`index.js` 已为该路径配置 raw body，回调 handler 应使用 `req.rawBodyForWechat` 验签。

回调处理要点：

1. 验签 + 解密 `resource` 得到 `out_trade_no`、`transaction_id`、`trade_state`
2. **幂等**：同一笔已成功则直接返回 `{ code: 'SUCCESS', message: '成功' }`
3. 更新 `market_pay_transactions`：`pay_status=success`、`transaction_id`、`paid_at`、`notify_raw`
4. 更新对应 `MarketOrder` 并触发积分/分佣
5. 到家服务订单：若 `out_trade_no` 前缀为 `SOPAY_`，需同步更新 `ServiceOrder`（与 `servicePaymentController` 共用流水表时）

### 5.4 数据表 `market_pay_transactions`

若线上尚无此表，建议字段（与 `servicePaymentController` 用法一致）：

| 字段 | 类型 | 说明 |

| id | BIGINT PK | |

| pay_status | VARCHAR(32) | `created` / `success` / `failed` |
| amount | DECIMAL(10,2) | 订单金额（元） |
| transaction_id | VARCHAR(64) | 微信支付单号 |
| paid_at | DATETIME | |
| notify_raw | JSON/TEXT | 回调原文 |
| notify_count | INT | 通知次数 |
| last_notify_at | DATETIME | |
| created_at / updated_at | DATETIME | |

并新增 Sequelize Model：`MarketPayTransaction`。

## 6. 接口契约（前端已对接，请勿改字段名）

### 6.1 本地集市

#### POST `/api/v1/market/payments/create`

- **鉴权**：`Authorization: Bearer <token>`
- **Body**：

```json
{ "order_no": "M2025060112345678" }
```

- **成功响应**（`code: 0`）：

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "order_no": "M2025060112345678",
    "out_trade_no": "PAY_xxx",
    "amount": "99.00",
    "pay_mode": "wechat",
    "virtual_pay": false,
    "payment_mode": "wechat",
    "wx_pay_params": {
      "timeStamp": "1710000000",
      "nonceStr": "随机串",
      "package": "prepay_id=wx...",
      "signType": "RSA",
      "paySign": "Base64签名"
    },
    "timeStamp": "1710000000",
    "nonceStr": "随机串",
    "package": "prepay_id=wx...",
    "signType": "RSA",
    "paySign": "Base64签名"
  }
}
```

> 前端 `utils/marketPay.js` 会递归解析 `wx_pay_params` / `jsapi` / `payment` 等嵌套；建议 **顶层与 `wx_pay_params` 都带上五参**，并兼容蛇形：`time_stamp`、`nonce_str`、`pay_sign`。

**虚拟支付（仅开发、未配商户时）**：`virtual_pay: true`、`pay_mode: "virtual"` → 前端**不会**调 `wx.requestPayment`。

**真支付判定**：`virtual_pay !== true` 且 `signType === "RSA"`。

#### GET `/api/v1/market/payments/status`

- **Query**：`order_no=M...`
- **成功**：

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "order_no": "M...",
    "pay_status": "paid",
    "order_status": "pending_accept"
  }
}
```

前端轮询时认为以下均为已支付：`paid` / `success` / `paid_success`。

#### POST `/api/v1/market/pay/callback`

- **鉴权**：无（微信服务器调用）
- **成功**：HTTP 200 + `{ "code": "SUCCESS", "message": "成功" }`

### 6.2 到家服务订单

#### POST `/api/v1/service-orders/payments/create`

- **Body**：`{ "order_no": "SO..." }`
- **响应格式**：与集市相同（`code` / `msg` / `data`）
- **前置条件**：`status === pending_pay` 且 `pay_status === unpaid`
- **错误码**（HTTP 200，`code` 非 0）：
  - `20043` 用户未绑定 openid
  - `20044` 未配置微信支付
  - `20045` 微信统一下单失败
  - `20031` 订单状态不允许支付

#### GET `/api/v1/service-orders/payments/status`

- **Query**：`order_no=SO...`

## 7. 端到端流程

```
小程序                         后端                          微信支付
  |                              |                              |
  |-- POST payments/create ----->|                              |
  |                              |-- POST /v3/pay/transactions/jsapi ->|
  |                              |<-- prepay_id ----------------|
  |<-- wx_pay_params (RSA) ------|                              |
  |-- wx.requestPayment -------------------------------------->|
  |                              |<-- POST pay/callback --------|
  |                              |   (验签、更新订单)            |
  |-- GET payments/status ------>|                              |
  |<-- pay_status: paid ---------|                              |
```

## 8. 联调验收步骤

1. 服务器部署 `apiclient_key.pem`，填写 `.env`，`MARKET_PAY_VIRTUAL_SUCCESS=false`，重启服务
2. 商户平台确认 AppID 绑定、回调 URL 已登记
3. 小程序真机微信登录（确保 DB 有 openid）
4. 创建集市订单 → 调用 `POST /market/payments/create`
5. 确认响应：
   - 不应出现 `virtual_pay: true`
   - 不应出现 `signType: "MD5"`（当前 mock 特征）
   - 应为 `signType: "RSA"` 且 `package` 以 `prepay_id=wx` 开头
6. 小程序拉起收银台，完成支付（可用最小测试金额）
7. 查库：`market_orders.pay_status=paid`，`order_status=pending_accept`
8. 查日志：回调验签成功、`market_pay_transactions` 已更新
9. 可选脚本：`node scripts/test-market-pay-debug.js`（需有效 token）
