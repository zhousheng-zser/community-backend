# 后端接口文档 - 小区绑定与搜索功能

> 基础路径: `/api/v1`
> 
> 所有需要鉴权的接口需要在请求头中携带 token: `Authorization: Bearer <token>`

---

## 一、小区相关接口（无需鉴权）

### 1. 获取小区列表

**接口地址**: `GET /core/communities`

**功能说明**: 获取所有已激活的小区列表，支持按城市、关键词筛选，支持分页，支持按距离排序

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| city | string | 否 | 城市名称（模糊匹配） |
| keyword | string | 否 | 小区名称关键词（模糊匹配） |
| page | number | 否 | 页码，默认1 |
| page_size | number | 否 | 每页数量，默认20，最大100 |
| latitude | number | 否 | 纬度（用于距离排序） |
| longitude | number | 否 | 经度（用于距离排序） |

**请求示例**:

```javascript
// 基础请求
wx.request({
  url: 'https://your-domain.com/api/v1/core/communities',
  method: 'GET',
  success: (res) => { console.log(res.data); }
});

// 带筛选条件
wx.request({
  url: 'https://your-domain.com/api/v1/core/communities?city=上海&keyword=阳光&page=1&page_size=10',
  method: 'GET',
  success: (res) => { console.log(res.data); }
});

// 按距离排序
wx.request({
  url: 'https://your-domain.com/api/v1/core/communities?latitude=31.168&longitude=121.379',
  method: 'GET',
  success: (res) => { console.log(res.data); }
});
```

**响应示例**:
```json
{
  "success": true,
  "errno": 0,
  "list": [
    {
      "id": 1,
      "name": "阳光小区",
      "city": "上海",
      "district": "闵行",
      "address": "上海市闵行区合川路(地铁站)周边",
      "latitude": "31.1686100",
      "longitude": "121.3794400",
      "radius_meters": 300,
      "distance": 1234.56
    }
  ],
  "total": 3,
  "page": 1,
  "page_size": 20
}
```

**字段说明**:

| 字段 | 类型 | 说明 |
|------|------|------|
| id | number | 小区ID |
| name | string | 小区名称 |
| city | string | 城市 |
| district | string | 区域 |
| address | string | 详细地址 |
| latitude | string | 纬度 |
| longitude | string | 经度 |
| radius_meters | number | 服务半径（米） |
| distance | number | 与传入坐标的距离（米），仅当传入坐标时返回 |

### 2. 根据坐标/地址解析小区

**接口地址**: `POST /core/communities/resolve`

**功能说明**: 根据坐标或地址文本解析用户所在小区

**请求参数** (JSON Body):

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| latitude | number | 否 | 纬度 |
| longitude | number | 否 | 经度 |
| address | string | 否 | 地址文本 |

**请求示例**:
```javascript
// 根据坐标解析
wx.request({
  url: 'https://your-domain.com/api/v1/core/communities/resolve',
  method: 'POST',
  header: { 'Content-Type': 'application/json' },
  data: {
    latitude: 31.16861,
    longitude: 121.37944
  },
  success: (res) => { console.log(res.data); }
});

// 根据地址文本解析
wx.request({
  url: 'https://your-domain.com/api/v1/core/communities/resolve',
  method: 'POST',
  header: { 'Content-Type': 'application/json' },
  data: {
    address: '上海市闵行区合川路地铁站'
  },
  success: (res) => { console.log(res.data); }
});
```

**响应示例**:
```json
{
  "success": true,
  "errno": 0,
  "matched": true,
  "community_id": 1,
  "community_name": "阳光小区",
  "match_type": "geofence",
  "distance_m": 150.5,
  "center_name": "合川路地铁站"
}
```

**字段说明**:

| 字段 | 类型 | 说明 |
|------|------|------|
| matched | boolean | 是否匹配到小区 |
| community_id | number | 匹配到的小区ID |
| community_name | string | 小区名称 |
| match_type | string | 匹配类型：geofence（地理围栏）、keyword（关键词） |
| distance_m | number | 距离（米） |
| center_name | string | 中心点名称 |

### 4. 绑定小区

**接口地址**: `POST /user/community-bindings`

**功能说明**: 用户绑定一个新小区（最多可绑定3个）

**请求参数** (JSON Body):

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| community_id | number | 是 | 要绑定的小区ID |

**请求示例**:
```javascript
wx.request({
  url: 'https://your-domain.com/api/v1/user/community-bindings',
  method: 'POST',
  header: {
    'Authorization': 'Bearer ' + token,
    'Content-Type': 'application/json'
  },
  data: {
    community_id: 1
  },
  success: (res) => { console.log(res.data); }
});
```

**响应示例**:
```json
{
  "code": 0,
  "msg": "绑定成功",
  "data": {
    "id": 1,
    "community_id": 1
  }
}
```

**错误响应**:

| HTTP状态码 | 错误码 | 说明 |
|-----------|--------|------|
| 400 | 1001 | 小区ID无效 |
| 400 | 1002 | 小区不存在或已停用 |
| 400 | 1003 | 已达到绑定上限（最多3个） |
| 409 | 1004 | 已绑定该小区 |

## 五、数据库表结构

### communities 表

```sql
CREATE TABLE communities (
  id INT PRIMARY KEY AUTO_INCREMENT,
  name VARCHAR(100) NOT NULL COMMENT '小区名称',
  city VARCHAR(50) COMMENT '城市',
  district VARCHAR(50) COMMENT '区域',
  address VARCHAR(255) COMMENT '详细地址',
  latitude DECIMAL(10,7) COMMENT '纬度',
  longitude DECIMAL(10,7) COMMENT '经度',
  status ENUM('active','inactive') DEFAULT 'active' COMMENT '状态',
  sort_order INT DEFAULT 0 COMMENT '排序',
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
) COMMENT='小区表';
```

### user_community_bindings 表

```sql
CREATE TABLE user_community_bindings (
  id INT PRIMARY KEY AUTO_INCREMENT,
  user_id INT NOT NULL COMMENT '用户ID',
  community_id INT NOT NULL COMMENT '小区ID',
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  UNIQUE KEY uk_user_community (user_id, community_id),
  FOREIGN KEY (user_id) REFERENCES users(id),
  FOREIGN KEY (community_id) REFERENCES communities(id)
) COMMENT='用户小区绑定表';
```

## 六、注意事项

1. **Token 鉴权**: 除 `/core/communities` 和 `/core/communities/resolve` 外，其他接口都需要携带 token
2. **绑定上限**: 每个用户最多可绑定 3 个小区
3. **距离排序**: 使用 Haversine 公式计算球面距离，传入 latitude 和 longitude 时返回 distance 字段
4. **状态管理**: 小区状态为 `inactive` 时，小程序端不会显示该小区
5. **管理后台鉴权**: 管理后台接口需要先调用 `/auth/admin/login` 获取 adminToken
