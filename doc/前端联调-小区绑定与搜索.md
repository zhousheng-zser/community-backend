# 小区绑定与搜索 — 前后端联调说明

> 小程序定位改造：首页进入「选择小区」→ 搜索选点 → 绑定/切换（最多 3 个）。  
> 本文档可整份发给 **后端 API** 与 **管理后台（admin）** 同事。

---

## 1. 小程序交互流程

| 步骤 | 页面 | 说明 |
|------|------|------|
| 首页点定位 | — | 未登录且无 `scope.userLocation` → 弹窗引导授权；否则进入图1 |
| 图1 | `pages/bind-community` | 已选地址、搜索小区、当前定位、绑定列表（无「附近地点」） |
| 图2 | `pages/community-search` | 按地级市 + 关键词搜小区；地图 marker + 列表；点「选择」回图1 |
| 图1 绑定 | — | 未登录点绑定 → 登录页；已登录调用绑定 API（最多 3 个） |
| 切换当前 | 图1 | 更新 `users.community_id` + 本地 active；首页定位文案用当前小区名 |

未登录用户：可在图2 选择小区并在图1 **本地切换当前选择**（不写绑定表）；登录后再点「绑定」同步服务端。

## 2. 数据库设计

### 2.1 小区主数据 `communities`

每条小区一条记录，**`id` 为全局唯一小区 ID**（用户表、绑定表均引用此 ID）。

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | BIGINT PK AUTO_INCREMENT | 小区 ID |
| `name` | VARCHAR(100) NOT NULL | 小区名称 |
| `city` | VARCHAR(50) | 地级市（如「上海市」），图2 按市筛选 |
| `district` | VARCHAR(50) | 区/县 |
| `address` | VARCHAR(255) | 详细地址 |
| `latitude` | DECIMAL(10,7) | 纬度 |
| `longitude` | DECIMAL(10,7) | 经度 |
| `status` | VARCHAR(20) | `active` / `inactive` |
| `sort_order` | INT | 排序 |
| `created_at` / `updated_at` | DATETIME | |

仅 `status = active` 的小区出现在小程序列表与地图。

仓库已有 Sequelize 模型：`backend/src/modules/core/models/Community.js`（需 ALTER 补 `city`、`district`）。

### 2.2 用户当前选用 `users.community_id`

| 字段 | 类型 | 说明 |
|------|------|------|
| `community_id` | BIGINT NULL | FK → `communities.id`，**当前定位/服务使用的小区** |

切换「当前选择」、直约/帮帮/社区等接口传参，以该字段为准（与现网一致）。

### 2.3 用户绑定关系 `user_community_bindings`

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | BIGINT PK | |
| `user_id` | BIGINT NOT NULL | FK → `users.id` |
| `community_id` | BIGINT NOT NULL | FK → `communities.id` |
| `created_at` | DATETIME | |

- 唯一索引 `(user_id, community_id)`
- 每用户最多 **3** 条
- 绑定成功：插入 binding；若无当前选用可同步 `users.community_id`
- 解绑当前 active：删除 binding 后，将 `users.community_id` 置为剩余一条或 NULL

### 2.4 迁移

- 已有 `users.community_id` 非空：插入一条 `user_community_bindings`
- 种子数据补全 `city` / `district`

## 3. 小程序 API（前缀 `/api/v1`）

### 3.1 可绑定小区列表

**GET** `/core/communities`

| Query | 说明 |
|-------|------|
| `city` | 地级市（可选） |
| `keyword` | 小区名称模糊搜索（可选） |
| `page` / `page_size` | 分页（可选） |
| `latitude` / `longitude` | 距离排序（可选） |

**响应示例：**

```json
{
  "success": true,
  "errno": 0,
  "list": [
    {
      "id": 1,
      "name": "大华社区",
      "city": "上海市",
      "district": "宝山区",
      "address": "上海市宝山区…",
      "latitude": 31.28,
      "longitude": 121.48,
      "radius_meters": 3000
    }
  ],
  "total": 100
}
```

与现网差异：现网无 `city`/`keyword` 筛选；上线后小程序优先传 Query，未支持时前端临时全量拉取后本地过滤。

---

### 3.2 查看用户绑定列表

**GET** `/user/community-bindings`  
**鉴权**：Bearer token

```json
{
  "code": 0,
  "list": [
    {
      "community_id": 1,
      "name": "成都市龙泉驿区教育局新宿舍",
      "address": "…",
      "city": "成都市",
      "district": "龙泉驿区",
      "is_active": true
    }
  ],
  "active_community_id": 1
}
```

---

### 3.3 用户绑定小区

**POST** `/user/community-bindings`

```json
{ "community_id": 1 }
```

| HTTP | 说明 |
|------|------|
| 200 | 绑定成功 |
| 400 | 已满 3 个 / 小区不存在或 inactive |
| 409 | 已绑定 |

绑定成功后建议将 `users.community_id` 设为该 ID（若用户无当前选用）。

---

### 3.4 用户解绑小区

**DELETE** `/user/community-bindings/:communityId`  
**鉴权**：Bearer token

若解绑的是 `users.community_id` 对应小区：自动将 active 切到另一条 binding，或置 `users.community_id = NULL`。

---

### 3.5 切换当前选用小区

**PATCH** `/user/community-bindings/active`

```json
{ "community_id": 2 }
```

**必须**更新 `users.community_id = 2`（不删除 binding 行）。

## 4. 管理后台（admin）

**项目**：仓库 `admin/`（Vue3 + Element Plus）

### 4.1 页面需求

| 功能 | 说明 |
|------|------|
| 菜单 | 侧栏「小区管理」 |
| 列表 | id、name、city、district、address、status、sort_order、更新时间；支持搜索 |
| 新增 | 录入小区，保存后生成 `communities.id` |
| 编辑 | 修改名称、地址、坐标、市/区、排序 |
| 下线 | `status = inactive`，小程序不可见 |

### 4.2 Admin API（建议 `/api/v1/admin/communities`，管理员鉴权）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/admin/communities` | 分页列表 |
| GET | `/admin/communities/:id` | 详情 |
| POST | `/admin/communities` | 新增 |
| PUT/PATCH | `/admin/communities/:id` | 编辑 |
| PATCH | `/admin/communities/:id/status` | 上/下线（可合并到 PUT） |

与小程序共用 `Community` 模型；挂载 `backend/src/routes/adminRoutes.js`。
